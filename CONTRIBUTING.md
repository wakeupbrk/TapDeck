# Contribute feedback and documentation

[← TapDeck](README.md) · [Support](SUPPORT.md) · [Roadmap](docs/ROADMAP.md)

Thank you for helping improve TapDeck. This public repository accepts product feedback, bug reports and documentation improvements. Application development source and implementation plans are managed privately.

## Report a bug or suggest a feature

Start with [Support](SUPPORT.md) and the issue forms. Describe the problem or task you want to accomplish, rather than only a preferred implementation. Check existing issues first and keep one topic per report.

## Improve the documentation

For a typo, broken link or clearer setup instruction, open a focused pull request against `main`. Describe what changes and why. Check relative links and release URLs, and distinguish the current preview from planned features.

Use generic examples and redacted screenshots. Do not add private source, personal decks, pairing URLs, credentials, build logs or source maps. This repository’s role is public downloads, documentation and support.

Do not rewrite trial or privacy terms as part of a routine documentation fix. Earlier license grants and third-party licenses remain unaffected.

## Report security concerns privately

Follow [SECURITY.md](SECURITY.md). Do not publish working exploit details, active credentials or private data in public issues or pull requests.
